# Политика конфиденциальности приложения «Тренажер дыхания»

Дата вступления в силу: 14 сентября 2026 года  
Последнее обновление: 14 сентября 2026 года

Настоящая Политика описывает, какие данные обрабатываются при использовании мобильного приложения «Тренажер дыхания» (далее — «Приложение»), зачем это необходимо и какие возможности управления данными доступны пользователю.

Разработчик Приложения — «Лавка приложений». По вопросам конфиденциальности и удаления данных можно написать на **Putilich@yandex.ru**.

## 1. Какие данные обрабатываются

### Данные, хранящиеся только на устройстве

Без входа в аккаунт Приложение сохраняет на устройстве:

- настройки дыхательных тренировок, звука и вибрации;
- созданные пользователем техники и пресеты;
- историю тренировок, длительность тренировок и результаты задержек дыхания;
- расписание напоминаний;
- выбранные пользователем настройки аналитики и персонализации рекламы;
- системные ссылки на выбранные пользователем аудиофайлы.

Сами пользовательские аудиофайлы не загружаются разработчику или в Firebase. Приложение не запрашивает доступ к микрофону, камере, контактам или точной геолокации.

### Вход и облачная синхронизация

Вход в аккаунт является добровольным. При входе через Google, Яндекс или VK обрабатываются:

- идентификатор аккаунта в Firebase;
- выбранный способ входа;
- адрес электронной почты и/или отображаемое имя, если поставщик входа передал эти сведения;
- технические сетевые данные, необходимые для авторизации и защиты от злоупотреблений, например IP-адрес и сведения о клиентском устройстве, в объеме, определяемом поставщиком сервиса.

Токены Яндекса и коды/токены VK передаются по HTTPS в Firebase Cloud Function только для проверки личности и выпуска токена Firebase. Разработчик не сохраняет их в облачном профиле Приложения.

После входа в Cloud Firestore синхронизируются:

- настройки голоса, встроенной музыки, громкости и вибрации;
- созданные пользователем пресеты и параметры дыхательных фаз;
- история тренировок, длительность и результаты задержек дыхания;
- серия тренировок;
- расписание напоминаний;
- служебные поля версии схемы и времени обновления.

Профили разных способов входа хранятся раздельно. Пользовательские аудиофайлы и платежные данные в Firestore не загружаются.

### Покупки и подписки

Покупки и подписки обрабатываются сервисом RuStore Pay. Приложение получает сведения о продукте и состоянии покупки или подписки, необходимые для предоставления Premium. Номера банковских карт и другие платежные реквизиты разработчику не передаются и Приложением не сохраняются.

### Реклама и аналитика

До первого запуска рекламных и аналитических функций Приложение предлагает отдельный выбор. Аналитика и персонализация рекламы по умолчанию выключены; выбор можно изменить в настройках.

- **Yandex Mobile Ads** используется для показа рекламы. При выключенной персонализации может показываться неперсонализированная реклама. Рекламный сервис может обрабатывать технические данные устройства, идентификаторы, IP-адрес и сведения о взаимодействии с рекламой в объеме, необходимом для показа, защиты от мошенничества и измерения рекламы. Согласие на доступ к геолокации Приложение рекламному SDK не передает.
- **AppMetrica** включается только по выбору пользователя и используется для анализа работы Приложения и поиска ошибок. При выключении аналитики отправка новых аналитических данных отключается.

## 2. Цели обработки

Данные используются только для:

- работы тренировок, истории, напоминаний и пользовательских настроек;
- входа в аккаунт и восстановления синхронизированных данных на устройствах пользователя;
- проверки и восстановления Premium-покупок;
- показа рекламы;
- анализа стабильности и улучшения Приложения, если пользователь включил аналитику;
- обеспечения безопасности, предотвращения злоупотреблений и выполнения требований закона.

Разработчик не продает персональные данные пользователей.

## 3. Сторонние сервисы

Для перечисленных функций используются сторонние сервисы, которые обрабатывают данные по собственным условиям:

- [Google Firebase и Google Sign-In](https://firebase.google.com/support/privacy/) — авторизация, Cloud Firestore, Cloud Functions и размещение этой страницы;
- [Яндекс](https://yandex.ru/legal/confidential/) — вход через Яндекс, реклама и AppMetrica;
- VK ID — вход через VK;
- [RuStore](https://www.rustore.ru/help/legal/privacy-policy-users) — распространение Приложения, покупки и подписки.

Инфраструктура Firebase для облачного профиля и функции авторизации настроена в регионе `europe-west1`. Сторонние поставщики могут обрабатывать данные в других странах в соответствии со своими политиками и применимым законодательством.

## 4. Сроки хранения

- Локальные данные хранятся до их удаления в Приложении, очистки данных Приложения или его удаления с устройства.
- Облачный профиль хранится, пока пользователь пользуется синхронизацией, либо до получения и выполнения запроса на удаление.
- Технические журналы и данные сторонних сервисов хранятся в сроки, установленные соответствующими поставщиками и требованиями закона.
- Сведения о покупках хранятся RuStore в соответствии с правилами сервиса и требованиями к учету операций.

Резервное копирование локальных данных средствами Android для Приложения отключено. Восстановление поддерживаемых данных после переустановки возможно только после входа в тот же облачный профиль.

## 5. Защита данных

Передача данных между Приложением и облачными сервисами выполняется по HTTPS. Доступ к документу Cloud Firestore ограничен идентификатором вошедшего пользователя. В release-сборке диагностические сообщения Приложения удаляются средствами оптимизации кода.

Ни один способ передачи и хранения данных не может гарантировать абсолютную безопасность, однако разработчик применяет разумные технические меры для снижения рисков несанкционированного доступа, изменения или раскрытия данных.

## 6. Управление данными и права пользователя

Пользователь может:

- использовать Приложение без входа в аккаунт;
- в любой момент изменить настройки аналитики и персонализации рекламы;
- выйти из аккаунта и продолжить работу в локальном гостевом профиле;
- удалить локальные данные средствами Android;
- запросить сведения об облачных данных, их исправление или удаление, написав на **Putilich@yandex.ru**.

В запросе на удаление укажите способ входа и отображаемый в Приложении адрес электронной почты или имя. Не отправляйте пароль, токен авторизации или платежные реквизиты. Для защиты пользователя разработчик может попросить подтвердить принадлежность аккаунта. Запрос будет обработан в срок, предусмотренный применимым законодательством.

Удаление облачного профиля не отменяет активную подписку RuStore. Подпиской можно управлять отдельно в RuStore.
